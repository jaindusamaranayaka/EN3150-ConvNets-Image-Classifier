    \subsection{Model B: Depthwise-Separable
CNN}\label{model-b-depthwise-separable-cnn}

Model B keeps Model A's four-block topology and
\texttt{3\ -\textgreater{}\ 16\ -\textgreater{}\ 32\ -\textgreater{}\ 32\ -\textgreater{}\ 32}
channel progression. Each \texttt{3\ x\ 3} convolution is replaced by a
depthwise \texttt{3\ x\ 3} convolution followed by a pointwise
\texttt{1\ x\ 1} convolution, then ReLU and \texttt{2\ x\ 2} max
pooling. The resulting \texttt{32\ x\ 4\ x\ 4} feature map feeds the
same \texttt{Linear(512,\ 43)} classifier as Model A. ReLU avoids
exponential activations, and depthwise filtering reduces
multiply-accumulate work while keeping the comparison controlled.

At \texttt{64\ x\ 64} input, Model A has \textbf{45,643} trainable
parameters and about \textbf{9,459,200 MACs} per image. Model B has
\textbf{25,526} trainable parameters and about \textbf{1,420,800 MACs}
per image (approximately \textbf{85\% fewer MACs}). Model B is below the
100,000 parameter limit.
