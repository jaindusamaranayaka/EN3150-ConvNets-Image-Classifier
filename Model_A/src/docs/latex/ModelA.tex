convolutional neural network designed for edge-device deployment on the
German Traffic Sign Recognition Benchmark (GTSRB).

\textbf{Key Specifications \& Constraints:} - \textbf{Input Resolution:}
Downscaled to \(64 \times 64\) pixels to emulate a resource-constrained
edge sensor environment. - \textbf{Dataset Partitioning:} 70\% Training,
15\% Validation, and 15\% Testing with strictly disjoint splits. -
\textbf{Architecture:} Interleaved standard 2D convolutions
(\texttt{Conv2d}), ReLU activations, and max-pooling
(\texttt{MaxPool2d}) layers. - \textbf{Parameter Budget:} Sub-100k
trainable parameters (Model A achieves 45,643 parameters). -
\textbf{Hardware-Aware Design Justification:} - Uses \textbf{ReLU}
activation: Eliminates computationally expensive transcendental
operations (like exponential calculations in Sigmoid/Tanh), optimizing
inference latency on embedded CPUs/MCUs. - \textbf{Training Setup:}
Trained for 20 epochs using Cross-Entropy Loss and the Adam optimizer.

    \subsection{1. Data Preparation and
Preprocessing}\label{data-preparation-and-preprocessing}

In this section: 1. Traffic sign images are resized to \(64 \times 64\)
pixels. 2. Training data is augmented with color jitter and slight
rotation to improve model generalization. 3. Images are normalized to
\([-1, 1]\) using standard channel transforms. 4. The dataset is split
into training (70\%), validation (15\%), and testing (15\%) subsets with
a fixed generator seed (\texttt{seed=42}) for reproducibility. 5.
PyTorch \texttt{DataLoader} instances are prepared for batch training
and evaluation.

\subsubsection{Architectural
Specification:}\label{architectural-specification}

\begin{itemize}
\tightlist
\item
  \textbf{Feature Extractor:} 4 convolutional blocks interleaving
  standard \texttt{Conv2d} (\(3 \times 3\) kernel, stride 1, padding 1)
  and \texttt{MaxPool2d} (\(2 \times 2\), stride 2).

  \begin{itemize}
  \tightlist
  \item
    Channel progression:
    \(3 \rightarrow 16 \rightarrow 32 \rightarrow 32 \rightarrow 32\)
  \item
    Spatial resolution:
    \(64 \times 64 \rightarrow 32 \times 32 \rightarrow 16 \times 16 \rightarrow 8 \times 8 \rightarrow 4 \times 4\)
  \end{itemize}
\item
  \textbf{Classifier:} \texttt{Flatten()} followed by a single linear
  projection layer (\texttt{Linear(512,\ 43)}).
\item
  \textbf{Activation:} \textbf{ReLU} across all convolutional stages
  (hardware-friendly, avoiding exponentials).
\item
  \textbf{Total Trainable Parameters:} 45,643 parameters (strictly under
  the 100k edge constraint).
\end{itemize}
